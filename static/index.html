Evidence before conclusions.

XGBoost learns an assumed policy from 6,000 synthetic records; evaluation uses 1,200 separately generated records. Only 16 boolean signal combinations exist. High accuracy reflects rule imitation, not fraud detection. JEV receives those same four signals and the explicit policy.

What the measurements mean

Local latency includes feature conversion and inference. JEV latency includes the network round trip and response validation. Neither includes browser transport. Benchmark pairs run concurrently, one pair at a time. P95 on a small sample is exploratory.

Before a production decision

Demo policy: Block when failure and mandatory remediation are both true; otherwise Challenge for either flag or an unbound/unlinked device; otherwise allow. Review these assumptions against labeled login outcomes. No real access is granted.
